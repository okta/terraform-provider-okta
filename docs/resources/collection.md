# Resource: okta_collection

Manages a resource [Collection](https://developer.okta.com/docs/api/iga/openapi/governance.api/tag/Collections/). A collection groups apps and their entitlements so that they can be assigned to principals together. Add resources to a collection with `okta_collections_resource`, and assign it with `okta_collections_assignment`.

## Example Usage

```terraform
resource "okta_collection" "example" {
  name        = "Core Engineering Access"
  description = "Entitlements required for core engineering access"
}
```
