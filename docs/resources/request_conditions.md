# Resource: okta_request_conditions

Manages all [request conditions](https://developer.okta.com/docs/api/iga/openapi/governance.requests.admin.v2/tag/Request-Conditions/#tag/Request-Conditions) of a resource in a single configuration block.

When several `okta_request_condition` resources are declared for the same resource, Terraform creates them in parallel, so the order in which they reach the API (and therefore their effective priority in Okta) is nondeterministic. This resource sorts the conditions by `priority` and creates, updates and deletes them one at a time, so the priorities in Okta match the configuration.

~> **IMPORTANT:** Conditions are matched by `name`, which must be unique within the resource. Renaming a condition deletes the old condition and creates a new one.

~> **NOTE:** Do not manage the conditions of a resource with both `okta_request_conditions` and `okta_request_condition`. Conditions on the resource that are not declared in this resource are left untouched.

## Example Usage

```terraform
resource "okta_request_conditions" "example" {
  resource_id = "<resource_id>"

  condition {
    name                 = "Engineering"
    approval_sequence_id = "<approval_sequence_id>"
    priority             = 0
    status               = "ACTIVE"
    access_scope_settings {
      type = "RESOURCE_DEFAULT"
    }
    requester_settings {
      type = "GROUPS"
      ids {
        id = "<group_id>"
      }
    }
  }

  condition {
    name                 = "Everyone else"
    approval_sequence_id = "<approval_sequence_id>"
    priority             = 1
    status               = "ACTIVE"
    access_scope_settings {
      type = "RESOURCE_DEFAULT"
    }
    requester_settings {
      type = "EVERYONE"
    }
  }
}
```

## Migrating from `okta_request_condition`

Remove the individual resources from state without destroying them, then import the resource. Keep the condition names unchanged so they are adopted rather than recreated.

```terraform
removed {
  from = okta_request_condition.engineering
  lifecycle {
    destroy = false
  }
}

import {
  to = okta_request_conditions.example
  id = "<resource_id>"
}
```
