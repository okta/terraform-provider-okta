# Resource: okta_trusted_origin

Creates a Trusted Origin. This resource allows you to create and configure a Trusted Origin.

## Example Usage

```terraform
resource "okta_trusted_origin" "example" {
  name   = "example"
  origin = "https://example.com"
  scopes {
    type = "CORS"
  }
}
```

## Upgrading from v6.x.x

In v7.x.x, `scopes` changed from a list of strings to a block. Update existing configurations as follows:

```terraform
# Before
resource "okta_trusted_origin" "example" {
  name   = "example"
  origin = "https://example.com"
  scopes = ["CORS"]
}

# After
resource "okta_trusted_origin" "example" {
  name   = "example"
  origin = "https://example.com"
  scopes {
    type = "CORS"
  }
}
```
