# Resource: okta_collections_resource

Adds a resource (an app, group, or push group) to a resource [Collection](https://developer.okta.com/docs/api/iga/openapi/governance.api/tag/Collections/), optionally limited to specific entitlements and entitlement values.

## Example Usage

```terraform
resource "okta_collection" "example" {
  name = "Core Engineering Access"
}

resource "okta_collections_resource" "example" {
  collection_id = okta_collection.example.id
  resource_orn  = "orn:okta:idp:00o1example2AbCdE1d7:apps:oidc_client:0oa1example2AbCdE1d7"

  entitlements {
    id = "esp1example2AbCdE1d7"
    values {
      id = "ent1example2AbCdE1d7"
    }
  }
}
```

## Schema

### Required

- `collection_id` (String) Unique identifier for the collection. Changing this forces a new resource.

### Optional

- `entitlements` (Block List) Collection of entitlements and associated value identifiers (see [below for nested schema](#nestedblock--entitlements)). Updated in place.
- `resource_orn` (String) The [ORN](https://developer.okta.com/docs/api/openapi/okta-management/guides/roles/#okta-resource-name-orn) of the resource (app, group, or push group). Changing this forces a new resource.

### Read-Only

- `id` (String) The ID of the collection resource. Same as `resource_id`.
- `labels` (List of String) The governance labels associated with this resource, one JSON-encoded object per element (use `jsondecode`).
- `push_groups` (List of String) Push groups associated with an app collection resource, one JSON-encoded object per element.
- `related_apps` (List of String) The apps related to this resource, one JSON-encoded object per element. Only populated for `GROUP` resources.
- `resource_configuration` (Object) Server-resolved configuration details for this resource within the collection (see [below for nested schema](#nestedatt--resource_configuration)).
- `resource_id` (String) The unique ID for this resource within the collection.
- `resource_profile` (Object) A limited set of properties from the resource's profile (see [below for nested schema](#nestedatt--resource_profile)).

~> **Note:** The API returns `labels`, `related_apps` and `resource_profile` only when they are requested with an `include` query parameter, which this resource doesn't send. They are currently always empty.
