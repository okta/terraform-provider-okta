# Resource: okta_collections_assignment

Assigns a resource [Collection](https://developer.okta.com/docs/api/iga/openapi/governance.api/tag/Collections/) to a principal, granting the principal access to every resource in the collection. The assignment can be indefinite or end at `expiration_time`.

## Example Usage

```terraform
resource "okta_collection" "example" {
  name = "Core Engineering Access"
}

resource "okta_collections_assignment" "example" {
  collection_id   = okta_collection.example.id
  expiration_time = "2027-12-31T23:59:59Z"
  time_zone       = "America/Toronto"

  principal {
    external_id = "00u1example2AbCdE1d7"
    type        = "OKTA_USER"
  }
}
```

## Schema

### Required

- `collection_id` (String) Unique identifier for the collection. Changing this forces a new assignment.

### Optional

- `actor` (String) The flow that triggered the grant request. Enum: `"API"`, `"ACCESS_REQUEST"`, `"NONE"`, `"ADMIN"`. Defaults to `"API"` on the server. Changing this forces a new assignment.
- `expiration_time` (String) The date and time, in RFC 3339 format, at which the principal's access expires. Leave unset for indefinite access.
- `principal` (Block) The principal the collection is assigned to (see [below for nested schema](#nestedblock--principal)). Changing it forces a new assignment.
- `time_zone` (String) The time zone, in IANA format (for example `America/Toronto`), for `expiration_time`.

### Read-Only

- `assignment_type` (String) Collection assignment type or source, for example `INDIVIDUAL`.
- `id` (String) The ID of the assignment.
- `principal_profile` (Object) A limited set of properties from the principal's profile (see [below for nested schema](#nestedatt--principal_profile)). Populated on read.

## Update Behavior

Only `expiration_time` and `time_zone` are updated in place. They are sent as JSON Patch operations: `ADD` for a field that was unset, `REPLACE` for one that changed, and `REMOVE` for one that was cleared. Changing any other argument replaces the assignment.
