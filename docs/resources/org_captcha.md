# Resource: okta_org_captcha

As an option to increase org security, Okta supports CAPTCHA services to prevent automated sign-in attempts.

## Example Usage

```terraform
resource "okta_captcha" "test_captcha" {
  name       = "testAcc_replace_with_uuid"
  type       = "HCAPTCHA"
  site_key   = "random_key"
  secret_key = "random_secret_key"
}

resource "okta_org_captcha" "test" {
  captcha_id    = okta_captcha.test_captcha.id
  enabled_pages = ["SIGN_IN"]
}
```

## Upgrading from `okta_captcha_org_wide_settings`

`okta_org_captcha` replaces the deprecated `okta_captcha_org_wide_settings` resource. As part of the migration, the `enabled_for` attribute (a set of strings) was renamed to `enabled_pages` (a list of strings). Update existing configurations as follows:

```terraform
# Before
resource "okta_captcha_org_wide_settings" "example" {
  captcha_id  = okta_captcha.example.id
  enabled_for = ["SIGN_IN"]
}

# After
resource "okta_org_captcha" "example" {
  captcha_id    = okta_captcha.example.id
  enabled_pages = ["SIGN_IN"]
}
```
