# Resource: okta_authenticator_tac

Configures the Temporary Access Code (TAC) authenticator: the code length, character complexity, time-to-live limits, and whether a code can be used more than once.

~> **NOTE:** An org can have only one TAC authenticator. If one already exists, creating this resource fails with `409 Conflict`; import the existing authenticator instead (see [Import](#import)). Use the `okta_authenticator` data source with `key = "tac"` to look up its ID.

~> **NOTE:** Authenticators can't be deleted. Running `terraform destroy` removes the resource from state only, and the authenticator keeps its current settings in Okta.

## Example Usage

```terraform
resource "okta_authenticator_tac" "example" {
  key  = "tac"
  name = "Temporary Access Code"

  provider_tac {
    type = "TAC"

    configuration {
      length            = 12
      min_ttl           = 15
      default_ttl       = 45
      max_ttl           = 120
      multi_use_allowed = false

      complexity {
        letters            = true
        numbers            = true
        special_characters = false
      }
    }
  }
}
```
