# Data Source: okta_authenticator_tac

Retrieves a Temporary Access Code (TAC) authenticator from your Okta organization by `authenticatorId`.

The `id` must belong to an authenticator with key `tac`; reading any other authenticator type returns an error. Use the `okta_authenticator` data source with `key = "tac"` to look up the ID.

## Example Usage

```terraform
data "okta_authenticator" "tac" {
  key = "tac"
}

data "okta_authenticator_tac" "example" {
  id = data.okta_authenticator.tac.id
}
```
